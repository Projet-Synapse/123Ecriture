123Ecriture, votre atelier d'écriture local-first

Notes, tâches et calendrier dans un seul coffre de fichiers MDX qui reste sur votre appareil. Un compte est optionnel : il ne sert qu'à synchroniser.

Ce que vous y trouverez

✍️

Éditeur Markdown & MDX

Un éditeur puissant avec coloration, recherche dans la note et aperçu. Vos notes sont de vrais fichiers MDX, lisibles par n'importe quel autre outil.

🔗

Wikilinks

Reliez vos notes entre elles avec des [[liens]] et tissez votre propre réseau de connaissances.

📅

Calendrier & tâches

Des évènements datés et des listes de tâches cochables, versionnés avec vos notes dans le coffre.

🗄️

Coffre local

Local-first : le fichier sur disque est la source de vérité. Aucun serveur requis pour lire ou écrire.

☁️

Synchronisation optionnelle

Un compte (Supabase) permet de synchroniser le coffre entre vos appareils. Jamais un passage obligé.

🌗

Thèmes clair & sombre

Une interface sobre qui suit vos préférences système, pensée pour de longues sessions d'écriture.

Pourquoi « local-first » ?

Vos écritures vous appartiennent. Le fichier MDX sur votre disque est la source de vérité : vous pouvez l'ouvrir, le sauvegarder, le versionner ou le déplacer sans jamais dépendre de 123Ecriture. Le cloud n'est qu'un mécanisme de sauvegarde et de synchronisation, activé seulement si vous le décidez.
